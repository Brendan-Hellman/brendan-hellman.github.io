SOFTWARE / CASE STUDY 09

Analog-input acquisition GUI

Implemented / documented

A PyQt5 application for externally triggered MCC analog acquisition, with a standalone manual workflow and TCP integration with the experiment-control software. The interface follows a trace from arming through storage, live display, and later review.

PythonPyQt5MCC USB-231TCPHDF5CSV

My contribution

  • Separated acquisition, device backends, storage, history, plotting, and configuration into dedicated modules.
  • Added threaded acquisition, HDF5/CSV output, saved-run browsing, unit controls, and explicit real-versus-dummy backend selection.

Deliverables

  • Python application and automated-test source
  • README, GUI captures, and configuration templates

Recorded outcome

The documented workflow arms the real DAQ and waits for a physical trigger. A restricted dummy backend supports development on unrecognized computers; the portfolio capture shows synthetic traces.
