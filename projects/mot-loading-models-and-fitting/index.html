ANALYSIS / CASE STUDY 14

MOT-loading models and fitting

Code + saved analysis

Python translations of a Mathematica MOT-loading model, combining differential-equation solving with weighted nonlinear fitting. Saved notebooks preserve model overlays and residual plots for both algebraic and coupled-ODE approaches.

PythonSciPyNumPyJupyterODEsWeighted fitting

My contribution

  • Translated data scaling, model definitions, and numerical integration into Python/SciPy.
  • Implemented weighted least-squares fits, covariance-based uncertainties, confidence intervals, and residual analysis, including an eight-parameter fit variant.

Deliverables

  • Python scripts and Jupyter notebooks
  • Cached model/fit and residual figures

Recorded outcome

The work makes the modeling workflow inspectable in Python and preserves the distinction between model assumptions, fitted curves, and residual structure.

8 parametersDedicated full-fit script
ODE + fitNumerical model workflow

Status & scope

Figures are saved notebook outputs, not a newly reproduced analysis. Experimental validity and parameter identifiability are not established by the plots alone.

Credit & context

The scripts explicitly translate an existing Mathematica notebook. Model provenance is retained; the portfolio does not claim original authorship of the underlying physics model.
